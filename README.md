# Eram Tech Website

Multi-page static website for Eram Tech / Eram Aluminum.

## Routes

- `/` Home
- `/about/` About
- `/products/` Products overview
- `/products/windows/`
- `/products/doors/`
- `/products/cladding/`
- `/products/hand-rails/`
- `/products/sky-light/`
- `/products/garage-doors/`
- `/products/rollup-shutters/`
- `/projects/`
- `/contact/`

## Deploying to Vercel

1. Import this repository into Vercel.
2. Use the repository root as the project root.
3. No build command is required for the current static site.
4. Deploy. The included `vercel.json` keeps trailing slashes on routes so directory-style pages work cleanly.

## Notes

- The homepage uses a lightweight CSS 3D treatment instead of heavy WebGL for performance.
- Product pages are intentionally structured for future expansion with images, specs, and descriptions.
